==== 사전준비 ======

: AWS CLI설정 
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"  
unzip  -qq awscliv2.zip  
sudo ./aws/install

: 도커설정
curl -fsSL https://get.docker.com -o get-docker.sh  
sudo sh get-docker.sh 
sudo apt-get install -y docker-compose 
rm get-docker.sh  
※ rootless 모드 도커활용 
sudo apt-get install -y uidmap 
dockerd-rootless-setuptool.sh install 
(오류발생 예방을 위해 아래 2개 진행) 
sudo setcap cap_net_bind_service=ep $(which rootlesskit)
systemctl --user restart docker

: 샘플 이미지 작성 (For ECR)
git clone https://github.com/GaussJung/aws-ecs.git 
cd ~/aws-ecs/docker_example/cityhome 
( 이미지작성 및 구동완료)
docker compose up -d --build   
※ 위의 명령은 이미지작성과 컨테이너구동 동시에 진행 (즉, 아래 명령과 같음) 
cd ~/aws-ecs/docker_example/cityhome/webapp_docker
docker build -t cityhome . && docker run -it -d -p 80:80 --name  city80  cityhome 


==== ECR 이미지 등록 ====
[환경변수]
export  myAwsAccount=111122223333
※ 비고. 11112222333은 콘솔우측 상단에 표기된 계정번호로 변경 (이하 동일)

[ECR생성]  
aws ecr create-repository --repository-name  cityhome --region ap-northeast-2

[로그인] 
aws ecr get-login-password --region ap-northeast-2 | docker login --username AWS --password-stdin  ${myAwsAccount}.dkr.ecr.ap-northeast-2.amazonaws.com  
 
[ 태깅 ] 
docker tag  cityhome:latest  ${myAwsAccount}.dkr.ecr.ap-northeast-2.amazonaws.com/cityhome:latest 

[ 푸쉬 ] 
docker push ${myAwsAccount}.dkr.ecr.ap-northeast-2.amazonaws.com/cityhome:latest

[ ECS 생성 ] 
▶  STEP2-1. 클러스터 생성 :
aws ecs create-cluster    --cluster-name   myEcsSpotCluster  --capacity-providers FARGATE FARGATE_SPOT --region ap-northeast-2   

▶  STEP2-2. 테스크 생성

[로그그룹-필요시] 
aws logs create-log-group --log-group-name    /ecs/myEcsSpotWebServer    

[테스크정의]
aws ecs register-task-definition  --cli-input-json  file://myEcsWebServer-spot.json  
위의 작업은 반복시마다 태스크정의가 개정되어짐 (myEcsSpotWebFamily:1 --> myEcsSpotWebFamily:2)

※ 테스크삭제 (잘못만들어졌을 경우) 
aws ecs deregister-task-definition  --task-definition myEcsSpotWebFamily:1  
aws ecs delete-task-definitions   --task-definition myEcsSpotWebFamily:1

▶  STEP2-3. 서비스 생성   
https://docs.aws.amazon.com/AmazonECS/latest/APIReference/API_CreateService.html 

aws ecs create-service \
    --cluster myEcsSpotCluster \
    --service-name myEcsSpotService  \
    --network-configuration  "awsvpcConfiguration={subnets=['subnet-bbaa986d5','subnet-ddaabbbb67f1'],securityGroups=[sg-aaaa1111bbbb],assignPublicIp=ENABLED}" \
	--cli-input-json file://myEcsSpotService.json 


▶  LB + AutoScaling적용  

### 사전작업 - 자원생성 ### 
1. 로드밸런서 생성 
aws elbv2 create-load-balancer --name  myECS-SVC-LB --subnets  subnet-bde986d5 subnet-bdbb67f1 --security-groups sg-bb87ecd0   --region  ap-northeast-2   
 
2. 목표그룹 생성 
aws elbv2 create-target-group --name myECS-SVC-Group  --target-type ip --protocol HTTP --port 80 --vpc-id vpc-75db461d --ip-address-type  ipv4    --region  ap-northeast-2    
 
3. 리스너 생성 
(80) 
aws elbv2 create-listener --load-balancer-arn arn:aws:elasticloadbalancing:ap-northeast-2:111122223333:loadbalancer/app/myECS-SVC-LB/64181b149ada91af --protocol HTTP --port 80  --default-actions Type=forward,TargetGroupArn=arn:aws:elasticloadbalancing:ap-northeast-2:111122223333:targetgroup/myECS-SVC-Group/78acf3e1a4c15b45   

(443) 
aws elbv2 create-listener --load-balancer-arn arn:aws:elasticloadbalancing:ap-northeast-2:111122223333:loadbalancer/app/myECS-SVC-LB/64181b149ada91af  --protocol HTTPS --port 443 --certificates CertificateArn=arn:aws:acm:ap-northeast-2:111122223333:certificate/63ec49f5-717e-448f-89d1-49cfd95c9e3f  --default-actions Type=forward,TargetGroupArn=arn:aws:elasticloadbalancing:ap-northeast-2:111122223333:targetgroup/myECS-SVC-Group/78acf3e1a4c15b45

▶ 오토스케일링 적용 
 
[오토스케일링 수량조정]
- 사전수행 0개로 변경 
aws ecs update-service  \
--cluster myEcsSpotCluster \
--service 111122223333  \
--desired-count 0  

A1) 어플리케이션 오토스케일링 타겟 설정 ( 2개 ~ 6개)
- 중요사항 : Resource-ID : 클러스터명 + 서비스명 
aws application-autoscaling register-scalable-target \
--service-namespace ecs --scalable-dimension ecs:service:DesiredCount  \
--resource-id service/myEcsSpotCluster/111122223333 \
--min-capacity 2 --max-capacity 6 --region ap-northeast-2  
 

A2) 추적정책등록-CPU (CPU이용률 40% 초과시 자원증대, 확장시 70초간 확인, 수축시 60초 확인)
aws application-autoscaling put-scaling-policy \
--service-namespace ecs --scalable-dimension ecs:service:DesiredCount \
--resource-id service/myEcsSpotCluster/111122223333 \
--policy-name my-ecs-scaling-policy --policy-type TargetTrackingScaling \
--target-tracking-scaling-policy-configuration '{ "TargetValue": 40.0, "PredefinedMetricSpecification": {"PredefinedMetricType": "ECSServiceAverageCPUUtilization" }, "ScaleOutCooldown": 70,"ScaleInCooldown": 60}'
